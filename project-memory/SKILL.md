# Project Memory

Store only information useful for consistent editing:
- explicit persistent style preferences;
- approved/rejected edit patterns with user explanation;
- known project constraints and tool configuration;
- versioned corrections and dates.

Distinguish:
- one-time instruction for a single edit;
- project-level preference;
- global preference only when explicitly confirmed.

Never infer a permanent preference from one correction. Ask when persistence is ambiguous. Do not store sensitive personal information or unrelated data.

Strict exclusions: no YouTube Analytics, views, watch time, retention metrics, audience demographics, OAuth, channel credentials, or performance dashboards. No automatic learning from platform performance.
