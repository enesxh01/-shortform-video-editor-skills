# Verification Status Standard

Use these labels consistently:

- **implemented-and-verified** — code/documentation exists and required tests were run successfully; include evidence and test environment.
- **implemented-unverified** — implementation exists but tests or real-footage validation are incomplete.
- **partial** — only some required behavior exists.
- **design-only** — documented design with no working implementation.
- **missing** — not implemented or documented.
- **blocked** — cannot proceed due to a named dependency, access, licensing, or environment blocker.

Never use "complete", "perfect", or "production-ready" as a substitute for evidence. Distinguish technical verification from creative human review.
